## 💡 Tips & Tricks

### Visual Tip 1: Color Harmony

```
Good Color Combination:
████ Primary (Blue)
████ Secondary (Dark Blue)
████ Accent (Cyan)
✓ Colors are harmonious

Bad Color Combination:
████ Primary (Red)
████ Secondary (Green)
████ Accent (Purple)
✗ Colors clash
```

### Visual Tip 2: Contrast

```
Good Contrast:
┌─────────────────────┐
│ ████████████████   │ Dark background
│ Light text         │ Light text
└─────────────────────┘
✓ Easy to read (7:1 ratio)

Bad Contrast:
┌─────────────────────┐
│ ████████████████   │ Gray background
│ Gray text          │ Gray text
└─────────────────────┘
✗ Hard to read (2:1 ratio)
```

### Visual Tip 3: Spacing

```
Good Spacing:
┌─────────────────────┐
│                     │ ← Padding
│  Content            │
│                     │ ← Padding
└─────────────────────┘
✓ Comfortable to read

Bad Spacing:
┌─────────────────────┐
│Content              │ ← No padding
└─────────────────────┘
✗ Cramped
```
