# WOOW! Admin - Quick Start Guide

Get started with WOOW! Admin in 5 minutes! This guide covers the essentials to transform your WordPress admin panel.

---

## 🚀 Quick Start in 3 Steps

### Step 1: Access WOOW! Admin

1. Log in to your WordPress admin panel
2. Find **WOOW! Admin** in the left sidebar
3. Click to open

### Step 2: Choose Your Style

**Option A: Apply a Color Palette** (Quick color change)
1. Click **Palettes** in the sidebar
2. Browse the 10 available palettes
3. Click **Apply** on your favorite
4. Done! Your colors are updated

**Option B: Apply a Design Template** (Complete transformation)
1. Click **Templates** in the sidebar
2. Browse the 11 available templates
3. Click **Apply** on your favorite
4. Done! Your entire design is transformed

### Step 3: Customize (Optional)

1. Click any tab in the sidebar (Admin Bar, Menu, etc.)
2. Adjust settings to your liking
3. Press `Ctrl+S` to save
4. Your changes are applied instantly

## ⌨️ Essential Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+S` | Save settings |
| `Ctrl+Z` | Undo (restore last backup) |
| `Ctrl+Shift+1-0` | Apply palettes 1-10 |

**Mac users:** Use `Cmd` instead of `Ctrl`

## 💾 Backup & Restore

### Automatic Backups

WOOW! Admin automatically creates backups:
- ✅ Before applying any palette
- ✅ Before applying any template
- ✅ Before importing settings

**You're always protected!**

### Restore a Backup

**Quick Method:**
- Press `Ctrl+Z` to restore the last backup

**Manual Method:**
1. Go to **Advanced** tab
2. Find **Backup & Restore** section
3. Click **Restore** on any backup

## 🎯 Common Tasks

### Change Admin Bar Color

1. Go to **Admin Bar** tab
2. Find "Background Color" setting
3. Click the color picker
4. Choose your color
5. Press `Ctrl+S` to save

### Enable Glassmorphism Effect

1. Go to **Effects** tab
2. Toggle "Enable Glassmorphism" to ON
3. Adjust blur strength (12-16 recommended)
4. Adjust opacity (0.85-0.95 recommended)
5. Press `Ctrl+S` to save

### Change Typography

1. Go to **Typography** tab
2. Select "Body Font" from dropdown
3. Adjust "Body Font Size" slider
4. Select "Heading Font" from dropdown
5. Press `Ctrl+S` to save

### Customize Login Page

1. Go to **Login Page** tab
2. Choose background type (solid, gradient, or image)
3. Adjust form styling
4. Customize button colors
5. Press `Ctrl+S` to save

## 🔧 Troubleshooting

### Changes Not Showing?

1. **Hard refresh:** Press `Ctrl+Shift+R` (Windows) or `Cmd+Shift+R` (Mac)
2. **Clear cache:** If using a caching plugin, clear its cache
3. **Regenerate CSS:** Go to Advanced tab → Click "Regenerate CSS"

### Want to Start Over?

1. Go to **Advanced** tab
2. Find **Backup & Restore** section
3. Click **Restore** on your first backup
4. Or click **Reset to Defaults** to start fresh
