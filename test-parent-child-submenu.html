✅ Ten sam CSS! Submenu automatycznie pojawia się obok wąskiego menu!

🔑 Kluczowy CSS

/* Parent = position: relative */
.menu-item {
    position: relative;
}

/* Child = position: absolute, left: 100% + 4px */
.submenu {
    position: absolute;
    left: calc(100% + 4px); /* ← Automatycznie obok parenta! */
    top: 0; /* ← Wyrównane z górą parenta! */
}

/* Hover bridge - wypełnia 4px gap */
.menu-item > a::after {
    content: '';
    position: absolute;
    right: -4px;
    width: 4px;
    pointer-events: all; /* ← CRITICAL! */
}
💡 Dlaczego to działa? • Parent ma position: relative
• Child ma position: absolute
• left: calc(100% + 4px) = 100% szerokości parenta + 4px gap
• top: 0 = wyrównane z górą parenta
• Działa automatycznie dla KAŻDEJ szerokości menu!
