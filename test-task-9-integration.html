Event Flow

  1. User Changes Font/Weight → Input element changes
  2. GoogleFontsLoader → Handles internal preview panel update
  3. Main.js Event Handler → Catches change event
  4. State Update → Marks unsavedChanges = true
  5. Button Update → Updates save button state
  6. Live Preview Check → If realtimeEnabled is true
  7. Debounced Preview → Waits 300ms for more changes
  8. Update Live Preview → Collects form data
  9. Server Request → Generates CSS on server
  10. CSS Injection → Injects CSS into current page
