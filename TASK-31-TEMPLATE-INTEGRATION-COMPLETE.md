## How to Use

1. **Access the Admin Interface:**
   - Go to WordPress admin: `/wp-admin/admin.php?page=woow-admin`
   - Click on "Design Templates" tab in the sidebar

2. **Browse Templates:**
   - View all 11 available templates in a grid
   - See preview images showing how each template looks
   - Read descriptions and see characteristic badges

3. **Filter Templates:**
   - Click category filter buttons at the top
   - Filter by: All, Minimal, Modern, Corporate, Creative, Dark

4. **Apply a Template:**
   - Click the "Apply" button on any template card
   - Wait for "Applying..." message
   - See success notification
   - Page automatically reloads with new template applied

## Technical Details

### AJAX Endpoint

**Action:** `woow_apply_template`

**Request Parameters:**
- `action`: 'woow_apply_template'
- `nonce`: Security nonce
- `template_id`: ID of template to apply (e.g., 'modern_minimal')

**Response (Success):**
```json
{
    "success": true,
    "data": {
        "message": "Template \"Modern Minimal\" applied successfully!",
        "template_id": "modern_minimal",
        "template_name": "Modern Minimal",
        "css": "/* generated CSS */",
        "settings": { /* updated settings */ },
        "metrics": { /* CSS metrics */ }
    }
}
```

**Response (Error):**
```json
{
    "success": false,
    "data": {
        "message": "Error message",
        "code": "error_code"
    }
}
```

### Data Flow

1. **Page Load:**
   - PHP loads templates from `includes/data/templates-data.php`
   - Formats data for JavaScript
   - Passes via `woowAdminData.templates`

2. **JavaScript Init:**
   - TemplateSelector reads template data
   - Renders grid with preview images
   - Sets up event listeners

3. **Apply Template:**
   - User clicks "Apply" button
   - AJAX request sent to server
   - Server validates, creates backup, applies template
   - CSS regenerated
   - Success response sent
   - Page reloads with new styles
